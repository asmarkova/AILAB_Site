## 🔍 Особенности реализации

### Оптимизация для AI-ассистентов
Сайт оптимизирован для индексации AI-помощниками:
- Специальные мета-теги (subject, topic, summary, category)
- Разрешение в robots.txt для GPTBot, Claude-Web, PerplexityBot
- Структурированные данные для лучшего понимания контекста

### Русскоязычная оптимизация
- Все мета-теги на русском языке
- Поддержка Yandex (директивы, Host)
- Локализация Open Graph (og:locale="ru_RU")

### Динамические мета-теги
- Мета-теги генерируются динамически для каждой страницы
- Canonical URLs для избежания дублей
- Правильные breadcrumbs для навигации
